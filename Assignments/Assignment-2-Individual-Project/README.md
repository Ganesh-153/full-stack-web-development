
# Student Assignment Tracker

## Project Description
Student Assignment Tracker is a responsive web application that helps students organize, manage, and track academic assignments in one place.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- React
- JSON
- Vite

## Features
- View sample assignments
- Add new assignments with a title, subject, and deadline
- Mark assignments as completed or pending
- Filter assignments by All, Pending, and Completed
- Responsive design for mobile and desktop screens

## How to Run
1. Install Node.js.
2. Open a terminal in the project directory.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.
